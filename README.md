# AI専門家相談室

普段お使いのAI（ChatGPT・Claude・Gemini など）に、プロの聞き方で相談を引き継ぐためのウェブサイトです。
相談内容や、あなたの好み・考え方をもとに、複数の専門家による議論や調査、反対意見の検討などをAIに指示する「相談用の文章（プロンプト）」を作ります。

- 無料・登録不要
- 入力内容・履歴・プロフィールは、利用者のブラウザ内にのみ保存されます（「保存しない」設定も選べます）
- 当サイトは、相談内容を収集・送信しません。利用者が実行ボタンを押したときだけ、選んだAIサービスへ渡されます

## 注意事項
- AIの回答は、間違いを含むことがあります。医療・法律・お金などの重要な判断は、出典を確認し、必要に応じて専門機関にご相談ください。
- つらい気持ちが強いときは、一人で抱え込まず、専門の相談窓口をご利用ください。
